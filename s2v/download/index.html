Install ScreenToVideo

  1. When prompted, save the file to a convenient location on your computer.

Uninstall ScreenToVideo

  1. Ensure ScreenToVideo and its help window are closed.
  2. Click on the Windows Start button.
  3. Select Control Panel (or Settings → Apps on Windows 10/11).
  4. Double click on Add or Remove Programs (Programs and Features).
  5. Select ScreenToVideo, click on the Remove button, and click Yes.
