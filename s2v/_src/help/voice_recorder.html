This object enables you to add a voiceover on top of an existing recording. The audio clip created appears on the Timeline when the voice narration ends.

Voice over properties can be edited by clicking on the object in the Timeline.

In the Object Inspector, you can set the volume.

  1. Name
    The default name for a voice over is 'Audio X' ('Audio 1', 'Audio 2', and so onward), and this is visible in the name property of the object. You can change the name by deleting the default name and typing in another one.
  2. Volume Control
    Learn more
    Use the slider to set the volume value or enter it manually (0 to 200%). Enter Fade In and Fade Out values to specify the audio transitions (in ms: 0 to 2000).
